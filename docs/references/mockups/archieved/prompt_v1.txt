Generate a **high-fidelity Windows desktop UI mockup** for an app named **NeKode** — a premium, dark, agent-first coding workspace built around **terminal-based AI coding agents**.

## Visual style

Dark near-black / deep navy UI, subtle cool-blue accents, faint borders, thin dividers, compact power-user spacing, sharp modern sans-serif UI font, monospace terminals, restrained rounded corners, low visual noise, subtle green success states. Serious, technical, calm, premium. Not a VS Code clone, not a SaaS dashboard, not a normal chat app.

Use standard **Windows minimize / maximize / close controls**.

At top-left show a small **cat icon** next to `NeKode`.

Top-center:
`Search files, symbols, commands...`

Do **not** place Dictation or microphone controls in the global top bar.

---

## Top workflow strip

Create a **full-width workflow strip spanning the entire application width**.

It must contain **one continuous horizontal line** running across the workflow area, with the checkpoints placed on that line.

The lifecycle is:

`Intake ✓ — Planning ✓ — Implementation ● — Verification ○ — Hand-off ○`

Each checkpoint must have its own **visible subtitle directly underneath it**.

Required subtitles:

- `Requirements captured` under **Intake**
- `Plan generated` under **Planning**
- `Building the solution` under **Implementation**
- `Running tests` under **Verification**
- `Prepare for delivery` under **Hand-off**

Important:

- the checkpoint line must remain visually continuous
- all checkpoint markers sit on that same line
- subtitles must be visible directly beneath their corresponding checkpoints

Implementation is active in blue.

On the right side show:

- `Current task`
- `Step 3/6`
- `Implementing chat UI components`
- `Details ▾`
- `All Tasks`

`Details` must clearly look expandable with a downward chevron or equivalent disclosure icon.

Do **not** show `All Active Tasks`.

---

## Agent controls

Directly below the tabs.

There are **exactly two segmented control groups**.

### Group 1

One connected segmented control:

`[ handoff icon Hand Off | resume/play icon Resume ]`

`Hand Off` and `Resume` must visibly belong to **one unified control**.

### Group 2

Immediately beside it, show another connected segmented control:

`[ stop icon Stop | continue icon Continue ]`

`Stop` and `Continue` must be styled **exactly like the Hand Off / Resume pair**.

Use:

- `Stop` → square/terminate command icon
- `Continue` → play/forward/execute-command icon

Do **not** show `Start`.

### Agent prompt input

At the **bottom of this same main agent console**, include a console-style prompt/input row where the user can type the next instruction.

It must feel like a **terminal command prompt**, not a normal chat composer.

Example placeholder:

`> Tell the agent what to do next...`

or:

`> Make the streaming handler reusable and add retry support...`

Include a visible terminal cursor.

### Dictation control

Inside this same prompt/input row, place a compact **Dictation** control on the **far right side of the input**.

Use:

- microphone icon
- optional subtle `Dictation` label

It should look like part of the console input controls.

Important:

- Dictation belongs **inside the main agent console input row**
- place it on the **right side of the prompt input**
- do not place Dictation anywhere else
- do not place a microphone control in the top bar
- do not place Dictation in the right Repository column
