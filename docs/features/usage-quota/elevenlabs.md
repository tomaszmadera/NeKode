# ElevenLabs adapter removal

NeKode no longer ships the `usage-elevenlabs` adapter (`elevenlabs-subscription`). Its source, registration and packaged resources were removed by the user-approved PDH-13 change on 2026-10-24.

A separately installed copy under `<userData>/usage-adapters` remains a user adapter. This change does not delete that copy, saved sources or credentials. Remove any copy or saved source you no longer want through your own adapter directory or Usage settings.

The ElevenLabs integration and its stored data in Personal Data Hub remain. See [current shipped adapters](usage.md) for supported NeKode setup.
