# OpenRouter adapter removal

NeKode no longer ships the `usage-openrouter` adapter (`openrouter-credits`). Its source, registration and packaged resources were removed by the user-approved PDH-13 change on 2026-10-24.

A separately installed copy under `<userData>/usage-adapters` remains a user adapter. This change does not delete that copy, saved sources or credentials. Remove any copy or saved source you no longer want through your own adapter directory or Usage settings.

OpenRouter balance remains only in Personal Data Hub and Rainmeter. The OpenRouter integration and its stored data in Personal Data Hub remain. Generic balance metrics remain supported for user adapters. See [current shipped adapters](usage.md) for supported NeKode setup.
